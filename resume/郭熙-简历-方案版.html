XEYO - 桌面 Agent 引擎 独立开发 2026.05 - 2026.07
从零实现桌面 Agent 引擎，支持多会话、后台任务、工具调用、权限控制和长任务执行。
技术栈：Python / FastAPI / Tauri / React / pytest
  • 任务执行：搭建逐题轨迹与 verifier 复盘流程，验证引擎对复杂编码任务的提升；官方中立 scaffold 在 32 道题上 157 次 trial 均未通过，XEYO 通过其中 13 道（40.6%）。
  • 上下文管理：将用户输入、引擎状态和系统事件分层处理，减少重复注入对上下文的影响；基于 28 天、9,144 次调用的真实账本，长上下文缓存命中率中位数达到 98.54%。
  • 多代理协作：设计子代理独立循环与独立存储，共享父级取消信号并隔离中间过程；主代理只接收结算结果，工具面按任务裁剪后下发。
  • 安全与恢复：将权限裁决、内容寻址快照和条件回滚接入统一执行流程；授权指纹不包含模型可控参数，文件状态不一致时拒绝强制覆盖，支持冲突检测与幂等重试。
  • 开发工具优化：实现 AST 符号索引，为代码读取提供按函数定位能力；单个函数读取量由 20,523 降至 206 token，符号召回率达到 100%，高于正则检索的 51%。
RXY-Agent - Java RAG 知识库系统 独立开发 2026.04 - 2026.05
面向企业知识库场景实现 RAG 系统，覆盖文档 ETL、混合检索、证据判断、权限过滤和性能优化。
技术栈：Java 21 / Spring Boot / Milvus / Kafka / Redis / Neo4j
  • 知识入库：使用 Tika 解析文档，完成标题感知分块、上下文增强和双向量入库；将 ACL 位图下推至 Milvus 查询层，未授权内容不进入候选集。
  • 检索优化：将文档名和章节路径加入重排输入，结合文档级置信度门控与向量、重排、BM25 融合；黄金集 20 例平均 Precision 从 0.769 提升至 0.954（含一次 embedding 升级），同主题文档混淆残余降至 2 例。
  • 回答与记忆：设计无需 LLM 的证据充分性判断、免 LLM 重检索和记忆分流流程，对知识问答、用户记忆和库外问题分别处理，减少检索不足时的直接生成与一刀切拒答。
  • 性能优化：通过虚拟线程、实体缓存、连接池调整和 rerank 结果缓存定位并缓解高并发瓶颈；200 并发下服务端检索 p95 从 2,222ms 降至 404ms。
