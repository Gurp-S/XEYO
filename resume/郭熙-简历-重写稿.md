`2026.05.2026.07`　**XEYO — 自研桌面 Agent 引擎**　　　　　　独立完成

用 Python 从零实现的桌面 AI Agent 引擎，包含 Agent 主循环、工具系统、上下文工程、记忆与权限安全，支持多会话并行、任务后台执行与小时级长任务稳定运行。

**实测**　deepseek-v4-flash 同模型，Terminal-Bench 2.1 官方 89 题：引擎实跑 182 次 trial 覆盖 57 题；在官方中立 scaffold 单次全量**打不下的 32 道硬题上攻下 13 道（40.6%，官方 0%）**

- **公开基准实战**：把"失败"从笼统的"模型不行"变成可执行的改进清单 —— 逐题留存轨迹与 verifier 原始输出，按**判分基建假阴性**与**真实能力缺口**分开归类（同一批失败里 7 道是镜像依赖网络安装被打断的判分问题，不该算模型不会）—— 34 道失败题完成取证分类。

- **长任务预算与 Goal 状态机**：解决两件相反的事，既不能在第 N 轮被硬切只留半句话，也不能让 Agent 无限自我续跑烧钱 —— 预算只开两根轴（**回合 256 / 工具调用 64**），首次触顶不开杀，而是开 **3 轮收尾窗**、窗内仍放行 3 次工具（长命令自动转后台），窗尽才落停止事件；目标侧是 **5 态白名单状态机**（非法转移只记日志、不打断当前轮），用 `revision` 做 CAS、冲突返 409 并回传当前目标；**轮次只在合成轮真正被引擎接受后才计数，人类轮不消耗配额**；唤醒预算与后台任务共享、上限 3，且**只有人类输入能把它回满**——自产出不恢复预算，从结构上杜绝自我续跑。

- **停滞检测**：真实事故是模型在同一个失败命令上**连续重试 166 次**把预算烧光 —— 在执行层做逐字节重复判定，**四档**：①同一调用签名连续 ≥6；②尾部窗口出现 k∈{2,3} 的周期；③结果摘要 `sha256[:16]` 连续 ≥3 次完全相同；④同工具连续 ≥4 次无新内容。命中即**不执行该次调用**、回一条中性结果；**被拒时不更新签名，同签名再来仍被拒**（不静默放行）；连拒 3 次才放行一次半开探针，拒绝全部落 `loop_break.jsonl` 取证。

- **可逆执行与崩溃恢复**：回滚不能靠重算，也不能在并发下"猜" —— 文件快照存成 **SHA-256 内容寻址 blob**（JSONL 里只存 hash、绝不存正文），逆操作日志**每行写一整份状态镜像**、读端按 `operation_id` fold 取最新、半行坏行直接跳过（容忍崩溃尾页）；回放不是重放而是**条件写**：先校验当前文件 hash 是否等于 `after_hash`，不符就抛冲突**绝不 force**，执行前再拍一份 pre-rollback 快照保证幂等重试，且必须持同一 `plan_hash` + 未过期 + 同一 revision 才放行。

- **工具系统**：解决"模型可任意执行本地命令""一个 4 万字输出吃满上下文""bash 卡死杀不掉孙进程" —— 执行收口在一条固定链上（只读门禁 → 钩子 → 权限三态 → Bash 路由 → 执行 → 输出预算 → 后置钩子/审计）；Bash 子进程挂在 **Windows 作业对象**上（`KILL_ON_JOB_CLOSE`，内存上限 2048MB），整树终止**故意不用 `TerminateJobObject`**（嵌套作业下会阻塞）而走 `taskkill /T /F`；超时按命令族分级（pip 300s / cargo 420s，默认 120s、上限 600s）；输出超 16000 字符先落盘（保留 7 天）再返回"头 6000 + 尾 2000 + 原文路径"，Bash 另有一条 30000/20000/8000 的 seam 并**从中段抢救最多 8 行错误证据** —— **权限裁决 p95 1.36ms / p99 1.66ms（n=2 万次混合工具形态实测）**。

- **符号定位**：读一个小函数原本要先 Read 全文再看，两轮烧 2 万 token；正则 grep 又抓不全 —— 用 **Python `ast` / tree-sitter 建符号表**（缓存键取 `(size, blake2b16)`，**不依赖 mtime**，所以 checkout 后不会整仓失效），`Read(symbol=…)` 精确切片到符号起止行，`Grep(output_mode="symbols")` **完全不调 ripgrep**、只回签名与行号范围 —— **读一个符号 20,523 → 206 token；仓库符号召回 100%（480/480）对比正则 grep 51%（244/480）**。

- **上下文工程**：system 里只要放日期、模型名、工具清单，换一天或换一次模型就整段 KV 前缀失效、全量重算 —— 按**写入权**把上下文切成三区：左段由会话级缓存产出（**字节稳定**）、历史只允许追加、易变内容每轮重建且**只改投影、绝不进历史**；易变块的物理实现就是**在投影末尾新增一条原生 system 消息**（一行 `[*messages, {...}]`）——KV 按最长公共前缀命中，**只有纯追加能让既有字节原地不动**，且新档正文不含任何随机量。压缩分三级：C0 单结果超 8192 字符截断 → C1 把冻结区结果换成无损存根（原文不删、可重取）→ C2 有损摘要须同时过**压力门 0.80** 与**收益门**（≥4000 字符 且 省 ≥25%），切点强制落在 `tool_use ↔ tool_result` 成对边界、保留最近 3 轮 —— **真实用量账本 28 天 9,144 次调用、累计 5.31 亿 prompt token：长上下文请求（≥50k token）缓存命中中位 98.54%、P90 99.58%（n=2,902），≥200k 超长档中位 99.56%，单请求峰值 49.6 万 token 命中 99.8%**。

- **分层记忆**：解决"模型自我强化的幻觉被当事实晋升"与"子代理把临时推断写进长期记忆" —— 长期事实走**候选 → 晋升两段**，晋升门 `can_promote` 只认**证据集合成员**（用户确认 / 已核实事实 / git diff 佐证 / 收割标记，或 ≥2 个独立会话同时出现），**纯"重复出现"一律拒绝**；置信度按来源封顶（用户 1.0 / diff 佐证 0.85 / **模型自收割 0.6**）；子代理三重隔离（工具面剔除记忆工具、落盘键隔离、主历史只回传一条摘要）；检索层首行明令**禁止调模型**，用关键词 + **CJK 2/3-gram**（不上分词器）+ 置信度 + 近因重排，查询词上限 3 —— 单轮晋升上限 8 条、冷却 6 小时。

- **权限与安全**：解决"未知工具静默放行""一次授权永久有效""提示注入伪造身份" —— 裁决是一条 **11 个判定点的顺序链**，**未知工具兜底走 ASK**（新增工具忘配元数据只会"每次都要问"，不会静默放行）；授权指纹的输入里**没有任何模型可控字段**（MCP 只绑注册名、Bash 只绑命令前两个 token，**参数永不参与**），且**组合命令不吃授权**（堵住 `git status && curl|sh` 蹭前缀）；扩展停用即 DENY，且该分支**先于授权匹配判定**，grant 不可穿越 —— 挂起审批 TTL 危险 60s / 普通 180s，超时前 30s 提醒；危险命令黑名单 19 条正则覆盖 10 类（打根删除、磁盘格式化/擦除、远程管道执行、fork 炸弹、编码 PowerShell 等）。

- **扩展系统（MCP）**：会话中途加工具会改 tools 数组，而 tools 数组位于请求最前、是 KV 前缀的一部分——**改一次就全量重算** —— 所以工具面做成**会话起点快照**（`schemas()` 首次构建后缓存，会话内启停永不触碰），会话内新增工具的唯一通道是起点就注册好的**一个网关工具**（约 150 token 固定 schema，提供 list/describe/call/resources 五个动作）；网关**身份是查出来的、不是听来的**（只在已知注册工具集内解析，模型参数不参与身份构造，解析不到即 fail-closed）；配置损坏走 keep-last-good + 审计，且默认档是全关——最坏只会"回到全关"，绝不静默启用。
