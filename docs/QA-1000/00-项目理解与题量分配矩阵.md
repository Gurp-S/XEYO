## 1. 项目定位（一句话）

**XEYO = 本地运行的编码 Agent**：Python 编排的「模型 ↔ 工具」多轮主循环引擎，配三种界面形态（Tauri 桌面 GUI / Ink 终端 TUI / Typer CLI），带企业级权限沙箱、流式 Stop、文件级回溯 rewind v3、多表面会话与微信远程通道。

**架构分层（7 层，用于题目模块归类）**

| 层 | 名称 | 承载包 |
|---|---|---|
| L1 | 决策层 | `engine/`（query_engine, query_loop, plan, scheduler） |
| L2 | 认知层 | `memory/`, `prompt/`, `codeindex/` |
| L3 | 能力层 | `tools/`（21 启用工具 + 110 文件） |
| L4 | 控制层 | `permissions/`, `rewind/`, `session/` |
| L5 | 容错层 | `engine/`（abort/budget/compact/repeat_guard/wrap_window） |
| L6 | 安全层 | `permissions/`, `audit/`, `SECURITY.md` |
| L7 | 装配层 | `server/`, `cli/`, `channels/`, `bridge/`, `sidecar/`, `gui/`, `tui/` |

### 3.5 启动与端口
- 默认：host `127.0.0.1`、port `8000`、frontend `5173`、CORS `http://localhost:5173`
- 端口被占 → 自动后移，实际端口写入 `.xeyo/backend_port`（JSON：`{port,pid,...}`）
- 前端经 `VITE_XEYO_HTTP_PORT` 获得实际端口
- 启动器按 `.xeyo/backend_port` 的 pid **杀进程树**后再启动
- 日志：`%TEMP%\xeyo-python_<RANDOM>.log`（RANDOM tag 防旧句柄占用）

### 3.6 门禁与 CI
- 本地：`pwsh -File scripts/check.ps1` = pytest(`-m "not live"`) + `slash.export_manifest --check` + `evals.changedetect check` + GUI typecheck/vitest + tui typecheck
- CI（`.github/workflows/ci.yml`）：3 job — python(pytest + manifest drift) / gui(npm ci + typecheck + test) / tui(typecheck)
- **CI 不跑 Playwright E2E**；本地门禁多跑 `changedetect check`

### 3.7 已知缺陷基线（用于「困难/超压」题的实证锚点）
`docs/全项目BUG排查-20260910.md` 已亲证 71 条，其中 6 条硬结论（轮转方向写反、flush 假成功、_PENDING 跨会话串台、bash 只读白名单越界、rm 黑名单只防 `/`、memdir 同文件覆盖、offload_read 无校验）。题库将把「能复现的缺陷」设计为**故障排查/根因分析题**，答案要求指出 `文件:行号`。
