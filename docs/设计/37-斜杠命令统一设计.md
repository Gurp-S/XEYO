# 37 · 斜杠命令统一设计（slash registry / dispatch / 多面接入）

> 目标：一套命令表，四处一致。CLI（Python REPL）、GUI（Web/Tauri）、CLI-TS（Node/Ink）、
> 远程通道（文件传输助手 / iLink）共用同一份 manifest 与同一套 server 命令执行；
> 未知 `/xxx` 一律报错不进模型（主流 Agent 行为），所有表面文案一致。

## 1. 分层

```
python/slash/registry.py        ← 单一事实源：Command 表 + 中文/英文别名 + parse_slash
python/slash/dispatch.py        ← server 命令执行器（20 个），CommandResult/DispatchContext
python/slash/export_manifest.py ← 生成 TS：gui/src/generated/slashManifest.ts
                                   cli-ts/src/generated/slashManifest.ts
python/server/routers/commands.py ← POST /v1/slash（Bearer 鉴权 + loopback 限制）
                                     POST /v1/slash/parse（调试：只解析不执行）
```

- `Command(name, category, handler, summary, usage, aliases, arg_spec, surfaces, when)`
- `handler`：`client` = 表面本地处理（只改请求体/contextvar，**不写 MessageStore/JSONL、
  不进 system 左段**）；`server` = dispatcher 执行，结果只作回复展示，**不产生模型轮**。
- `surfaces` ⊆ `("gui","cli","cli_ts","remote")`；`when`：`idle|always`（stop/allow/deny
  为 `always`，运行中也可用）。
- 导入期做别名冲突校验：重名 alias 直接 `RuntimeError`（防止手滑加重复别名）。

## 2. 命令总表（34 个）

client（表面本地）：help version docs clear mode output code model theme approval
retry run exit load demo
server（POST /v1/slash → dispatch）：status cwd usage context ls stop allow deny compact
transcript export rule doctor proposals git diff revert skills mcp plugins

要点：
- `/mode` 吸收旧 `/plan /ask /agent`（`plan/ask/agent` 不再是命令）。
- `/history` 是 `/transcript` 的别名；`/压缩 /compact` 中文别名互通。
- `/run` 只是**提示词变换**（`[slash:/run] 请用 Bash 工具执行…`），命令仍走权限门禁，
  绝不做服务端 exec。
- `/revert` 两步确认：先 `/<rewind_id>` 得到计划，再 `/<rewind_id> confirm` 执行。
- `git/diff` 只读（status/log/branch/diff），无任何写操作。
- 扩展命令（skills/mcp/plugins）在 `enabled_extensions` 总开关关闭时统一回复
  「扩展层默认关闭（.xeyo/settings.json 的 enabled_extensions）」。
- `compact/export/revert` 在 turn 运行中被 `_reject_if_busy` 拒绝。
- `/export`、`/ls` 拒绝路径逃逸（`..`/绝对路径/越界目录）。

### 明确不做的命令（对齐参考表后裁剪）

`/shell /read /cd`（Bash/Read 工具本身带权限门禁，命令是重复入口）、`/scroll-* /copy`
（终端 UI 细节，GUI 不需要）、`/config /save`（GUI 设置即持久化，REPL 无配置文件可写）、
`/verbose`（由 `/output off|lite|full|ultra` 取代）、`/sandbox`（审批策略
`/approval always|risk|never` 已覆盖）、`/hooks /bug /feedback`（XEYO 无对应设施）。

## 3. 别名规范（XEYO 风格）

英文名为本体；除语义特别明确的（如 `/help`、`/version`）外都配中文自然别名：
`目录→cwd`、`列目录→ls`、`用量→usage`、`上下文→context`、`停止→stop`、`允许/拒绝→allow/deny`、
`压缩→compact`、`历史→transcript`、`导出→export`、`规则→rule`、`体检→doctor`、`提案→proposals`、
`回滚→revert`、`技能→skills`、`主题→theme`、`模式→mode`、`精简→output`、`重试→retry`、`跑→run`。
远程通道裸词输入（不带 `/` 的整条消息恰为别名）等价于斜杠命令。

## 4. 各面接入

| 面 | 命令来源 | client 命令执行 | server 命令执行 |
| --- | --- | --- | --- |
| Python REPL | `slash.registry` | `cli/slash.py`（mode/output/code/approval/model…） | `slash.dispatch`（同进程） |
| GUI | `generated/slashManifest.ts` | `lib/slashCommands.ts`（settingsStore/chatUiStore） | `POST /v1/slash`，结果为 UI-only 系统气泡 |
| CLI-TS | `generated/slashManifest.ts` | `app/App.tsx`（config patch） | `POST /v1/slash`，结果为 system 行 |
| 远程通道 | `slash.registry`（白名单 9 个） | — | service 自实现 status/cwd/stop/allow/deny + dispatch rule/doctor/proposals |

约定：
- GUI/CLI-TS 的补全、`/help`、未知命令文案全部由 manifest 生成（`HelpPanel`、
  `PromptLine.slashMatches`、`slashSuggestions`）。
- GUI 结果气泡 `uiOnly: true`：不进 `toApiMessages`、不持久化到后端，避免污染模型上下文。
- 远程白名单：`help status cwd stop allow deny rule doctor proposals`；compact/transcript
  等暂不下放远程（后续按需放行）。
- 截图不进 manifest：自然语言「截图」→ `with_screenshot_nudge` 补系统提示 → 模型调
  Screenshot 工具（远程截图是能力不是命令）。

## 5. server 端点

`POST /v1/slash`（Bearer 鉴权；非 loopback 需显式允许）：

```json
{"name": "usage", "arg": "7", "session_id": "...", "workspace": "D:/proj",
 "provider": "deepseek", "base_url": "https://api...", "model": "deepseek-chat"}
```

响应：`{"handled": true, "kind": "server", "message": "…", "result": {...}|"null"}`；
`kind=client` 时 `handled=false`（表面应本地处理）；未知命令 `{"handled": true, "kind":
"error", "message": "未知命令 /xxx，试试 /help"}`。

`POST /v1/slash/parse` 返回 `{handled, unknown, name, handler, arg, when}`，供调试/校准。

## 6. 为什么这样收敛

- T_now 红线：开关类命令（mode/output/code/model/theme/approval）只改请求投影来源，
  不写历史、不进 system；`pre_llm_inject.py` 无需任何改动。
- 单一事实源避免四张表漂移（历史上 GUI 帮助、REPL 帮助、iLink `_HELP` 各写一份）。
- server 命令集中执行保证权限/审计/忙时拒绝的一致性，client 命令保持零网络依赖。
