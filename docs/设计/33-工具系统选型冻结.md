# 工具系统 · 选型冻结

> 状态：**已冻结 · 终稿**（2026-08-29）  
> 落地必须严格按本文件。后续加 tool **只扩表、不改骨架**；多 Agent **runner / 调度**不在本冻结范围（见 [28-多Agent协同设计](./28-多Agent协同设计.md)）。

## 底座（不可改）

| 层 | 选型 | 说明 |
|----|------|------|
| 元数据真源 | **`tools/meta.py` · `TOOL_META`** | 每工具一行：`read_only` / `concurrency_safe` / `policy` / 子 agent / 短 description / 注入需求 / 重复闸豁免 |
| 启用矩阵 | **`ENABLED_TOOL_ENTRIES`** | `(name, factory)`；启动时与 `ENABLED_META_NAMES` 对齐，漂移即 `RuntimeError` |
| 工厂索引 | **`TOOL_FACTORY_BY_NAME`** | O(1) 按名取工厂；子注册表禁止「先实例化再读 name」双建 |
| 执行入口 | **`ToolRegistry.run`** | 唯一执行门：policy →（ASK 协调）→ `execute`；审计 `tool.started/finished` |
| 权限 | **`evaluate_policy`** | 名表从 `meta` 派生；实例优先 `is_read_only()`；未知工具默认 **ASK** |
| 编排 | **`run_tools_partitioned`** | 只读并发 / 写串行；`is_concurrency_safe` 与 meta 同源 |
| 提示策略 | **`TOOL_POLICY`（system 左段）** | 跨工具纪律；细则在 schema 短 description，禁止 hint 与左段双写 |

### 加工具合同（严格）

新增 / 完善工具必须三步，缺一不可：

```text
1. tools/meta.py     ← 登记 ToolMeta（含 short_description）
2. tools/<pkg>/      ← execute() + prompt.py（全文说明可留包内）
3. catalog.py        ← ENABLED_TOOL_ENTRIES 加 (name, factory)
```

- **名三处一致**：`ToolMeta.name` == `tool.name` == catalog 声明名；注册时校验。  
- **flags 同源**：实例 `is_read_only` / `is_concurrency_safe` 必须等于 meta；注册时硬失败。  
- **副作用工具**（写盘 / shell / 外发）：须有边界测，证明拒绝或受限路径下不破坏工作区。  
- **禁止**：只改 `policy.py` 手抄名表；只进 ENABLED 不进 meta；子 agent 白名单另手写一份。

### Policy 种类（`ToolMeta.policy`）

| kind | 语义 |
|------|------|
| `always_allow` | 恒放行（如 getTime / TodoWrite / JournalQuery / echo） |
| `read_path` | 路径读闸（Read / Glob / Grep） |
| `write_path` | 写闸 + 审批模式（Write / Edit；Memory 特判 allow） |
| `outbound_ask` | 外发一律 ASK（Screenshot / SendToWeChat） |
| `bash` | Bash 专用评估链 |
| `agent_allow` | Agent spawn 默认 ALLOW；深度/白名单/写锁由工具+WriteStore 强制 |
| `interactive` | AskUserQuestion；模式特例，重复闸豁免 |

## 运行时合同（全部采纳 · 终稿口径）

| # | 能力 | 冻结口径 |
|---|------|----------|
| 1 | Schema 预算 | 默认用 meta `short_description` 发给模型；`XEYO_TOOL_SCHEMA_FULL=1` 才用包内全文 |
| 2 | 只读提前执行 | `arguments` `json.loads` 闭合即 yield `tool_use`；query_loop 对合格只读投机 `create_task`；**默认开**；`XEYO_EARLY_READONLY_TOOLS=0` 关 |
| 3 | 提前资格 | `concurrency_safe` ∧ `read_only` ∧ policy **ALLOW**（非 ASK）∧ 非交互/Agent ∧ 非 wrap-up |
| 4 | 提前禁区 | Bash / Edit / Write / Screenshot / SendToWeChat / Agent；XML `<tool_call>` 路径不提前 |
| 5 | 预算与闸 | 提前开火**不占** `begin_tool_call`；流后 admission 拒则 `cancel`，结果不进历史 |
| 6 | 重复闸 | `RepeatCallGuard`；豁免集 = `meta.REPEAT_EXEMPT_TOOLS`（含 TodoWrite / AskUserQuestion） |
| 7 | 子 agent 工具 | 基线 = `SUBSET_TOOL_BASELINE`；禁发 = `FORBIDDEN_SUB_TOOLS`（**无**过期名 `_agent`）；Memory 另由 `agent_scope` 剔除 |
| 8 | 注入协议 | `ReadStateAware` / `WriteStoreAware` / `AgentIdAware` / `RuntimeProviderAware`；meta 标明 need_* 却缺方法 → 硬失败 |
| 9 | 模式过滤 | ask/plan：优先实例 `is_read_only()`；无实例回退 `READONLY_ALLOW` ∪ 交互特例 |

### 只读提前时序（合同）

```text
SSE: tool_calls[i] args 可 loads ──► yield tool_use ──► 合格则 create_task(_run_one_tool)
SSE: [DONE]
      ──► repeat / budget / plan / mode 闸（原序）
      ──► early：await 或 cancel；其余：run_tools_partitioned
      ──► tool_result 严格按 tool_uses 原始顺序写回
```

## 明确不做

- 为加工具再引入外挂 hooks / 第二套 registry  
- 在模型层直接调工具（绕过权限 / 审计 / 预算）  
- 参数未 `json.loads` 就投机执行  
- 对 Bash / Edit / Write / 外发 / Agent 投机提前  
- 用 `tools_system_hint` 再拼一份「Available tools」进 append（必须保持空串）  
- 本冻结范围内重写 Agent runner / DAG 调度器（只冻结工具面与 catalog 合同）  
- 为「看起来能力多」继续堆 scaffold 空壳进 ENABLED  

## 收益边界（冻结口径，勿对外夸大）

- **解决**：工具变多时名表不散架；schema token 可控；只读与模型尾部生成重叠省墙钟；TodoWrite 同参刷新不被误拦；子 agent 禁发同源。  
- **不解决**：不提高模型选对工具的智力；不替代权限产品设计；多 Agent 调度正确性仍靠 WriteStore / runner（另线）。

## 落地入口

- `python/tools/meta.py` — **元数据真源** + 派生集合 + schema 预算  
- `python/tools/catalog.py` — `ENABLED_TOOL_ENTRIES` / 工厂索引 / 注册与注入  
- `python/tools/base_tool.py` — `Tool` + 注入 Protocols + `tool_flag`  
- `python/tools/tool_registry.py` — `run` / `schemas()`（套预算）  
- `python/tools/orchestration.py` — 分区执行 / `_run_one_tool`  
- `python/permissions/policy.py` — 从 meta 取名表；`evaluate_policy`  
- `python/engine/query_loop.py` — 只读提前 + 重复闸消费  
- `python/engine/repeat_guard.py` — 豁免 = `REPEAT_EXEMPT_TOOLS`  
- `python/engine/scheduler.py` / `subagent_context.py` — 基线/禁发 import meta  
- `python/prompt/system_prompt.py` — `TOOL_POLICY`  
- `python/tests/test_catalog.py` — 冻结矩阵 + meta 契约  
- `python/tests/test_early_readonly_tools.py` — 提前执行开关与重叠断言  

### 环境变量（冻结）

| 变量 | 默认 | 含义 |
|------|------|------|
| `XEYO_EARLY_READONLY_TOOLS` | **开**（未设或 `1`） | `0/false/off` 关闭只读提前 |
| `XEYO_TOOL_SCHEMA_FULL` | 关 | `1` 时 schema 用包内全文 description |
| `XEYO_REPEAT_TOOL_HINT_AT` / `BLOCK_AT` | 2 / 3 | 重复闸阈值（豁免工具不计） |

### 已冻结补充口径（2026-08-29）

- `tools/__init__.py` **懒导出** catalog，保证 `from tools.meta import …` 不触发 `policy↔bash` 循环导入  
- JournalQuery：`always_allow`（不再兼 read_path；恒放行优先）  
- Agent：`concurrency_safe=True` 且 `read_only=False`；可同轮并行 spawn，写冲突靠 WriteStore  
- 加工具时同步更新 `tests/test_catalog.py` 的 `_FROZEN_ENABLED`（能力矩阵显式变更）  
- **tools 前缀**：同会话内 tools 名表 + 短 description **字节稳定**；禁止中途增删工具。升级发版改 schema（多几个 optional 字段）只造成**升级后首轮**前缀 miss，之后仍可命中——与「会话中途挂载工具」不是一类问题。  
- **Read vision**：会话建表时按 `supports_vision_input(provider, model, modes)` 开关；描述与行为对齐；`XEYO_READ_VISION=0/1` 可强制。中途改模型应重建 registry（接受该次前缀重算）。
- **Glob 用法（短描述，非硬限制）**：已知子树再设 `path`（任意允许目录，**不**锁死 `src/`）；优先具体 pattern；截断用 `offset` 分页；文件名 Glob / 内容 Grep；勿 Bash find。
