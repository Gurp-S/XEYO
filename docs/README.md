## 品牌命名说明（收口）

对外**产品名**统一用 **XEYO**：`XEYO.bat` / `XEYO-CLI.bat` / CLI 口号 `Ӿ I am XEYO` / `XEYO_*` 环境变量均为此名。以下为历史与内部变体，外不混用：

- **XenYon**：仓库/工作区目录名（`D:\lea\XenYon code`）与早期产品名；仍残留在 `java/pom.xml`（"XenYon Tools"）与回溯 v2 合同（"XenYon Rewind v2"）中，非当前对外品牌。
- **xy-**：内部技术前缀，用于 CSS 类名（`xy-chat-*` / `xy-scroll-*`）、运行时产物（`.xy-shadow-git/`、`.xy-trash/`、`xy-window-*.png`）与 DOM id；非用户可见品牌。
- **XeyoPet**：XEYO 产品下的**桌宠功能子品牌**（`gui/src/XeyoPet/`、组件 `XeyoPet`、资源 `/XeyoPet`），对外称「XeyoPet 桌宠」。
