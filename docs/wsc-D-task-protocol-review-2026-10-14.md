# P0：任务产物验收入口——实施前三轮复审

具体改动限定为独立评测模块：任务时间轴、隔离产物写入、外部验收、A1/D首请求准备。不改生产引擎、Prompt、schema、投影、80%/85%或默认模型模式，不调用付费API。后续厂商适配、运行策略与语义修改各自再复审。

## 复审一：根因与替代选择

根因：旧observer主要输出JSON字段；数据正确、来源匹配甚至task_success标签都未证明模型执行了原任务。已有faithful/combined驱动可用于状态定位，不能直接当作任务产物验收。

v1曾准备沿用字段问答增加题数。否决：扩大QA并不能解决“未执行任务也成功”。修订：两个独立任务域，必须实际保存JSON产物；验收从磁盘读取并比较当前任务真值。热层不足时可用现有精确冷工具，原状态字段继续单列。

复用：原生D生成/Guard/事务接口、固定Codex A1源码prompt、已有冷源读取、现有原子写入原语与预算流水。新增：仅独立场景和产物验收入口；不新增生产状态、摘要authority或存储迁移。

## 复审二：失败、时间轴和边界

读过FileWriteTool/FileReadTool后否决直接调用全局文件工具作为初版评测入口：权限/rewind/读写lease与会话钩子会混入方法比较。隔离ArtifactWrite只按文件根目录约束执行，错误数据也可写入并被外部验收发现。它不冒充生产Write安全验收。

v2规则：源世界事件 → 本分支已见来源 → 密封归档 → 模型请求 → 实际产物写入 → 外部验收。未来事件、expected和 oracle不进当前请求，工具只能读当前密封归档；后来步骤的计划文件不能通过工具读取。取消/完成步骤要求无写入，用尝试记录和旧文件哈希检查，不能靠工具静默纠正模型的任务判断。

拒绝仅看文件存在、模型回复done或最终答案含正确JSON。缺文件、错目标、额外字段、错版本/单位/来源、写入已取消任务均失败。结果即使修正，错误写入次数仍保留。

写工具顺序执行，评测分支使用各自根目录；路径越界/符号链接越界拒绝；UTF-8原子发布与receipt记录复用现有原语。生成失败/支付停止仍沿用旧合法状态加pending来源，不能填gold修复。

## 复审三：公平性、准入和代价

否决一开始跑全部长会话×10代，也否决把合成控制任务称为真实生产闭环。初版仅免费准备，paid_run_allowed=false。A1/D同工具、任务、模式与产物标准；A1 pinned方法和D native方法保留各自差异，不能把原生D换成自写summary或弱化Guard。

两域分别是配置单位转换与素材清单汇总；artifact版本与execution revision独立，绑定明确。十步时间轴涵盖更新、迟到、问题解决、完成、重开、范围缩小、源数据刷新、取消与恢复。动态实际压缩/重启数量由后续驱动记录；静态十步准备不是10代通过。

首请求只含第一步已见来源、任务和工具，不包含后九步或expected。代码先通过真正有必要的外部验收反例：无文件、错误值/类型、错路径、越界、取消后写入。检查数量不算WSC收益。

最终v3：一份可复用的任务入口/外部oracle与两方法首请求。通过P1协议保真后，先校准完整来源能做对任务，再运行压缩续接；未压缩仍失败则不能归给WSC。以后同一驱动推进1/3/5/10代与留出任务，不再新增多个小QA脚本。

## 完成边界

本修改成功意味着：验收确实依赖实际正确产物；初始请求已冻结；场景真值、未来信息与文件范围隔离。它不意味着D优化成功、不证明模型实际完成任务、不完成旧228或媒体矩阵。

预计新生产状态/迁移/开关为0，初版付费请求为0。后续任何行为变化重新完成具体三轮。用户完整Goal及质量标准保持，所有旧结果和冻结前缀不改。
