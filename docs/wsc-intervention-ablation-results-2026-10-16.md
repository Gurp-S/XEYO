# 358：撤除干预对照结果

结论：本轮没有支持新的全局生产撤除。删除旧D保留检查放宽了正确纠错，也放宽了有效约束错误删除；删除三个重复语义字段在所测任务中质量相同、首请求小幅缩短，但另有生产投影反例证明这些字段并非始终重复。当前自然语言路径本来不附加整份D状态，本轮不能记为该路径新获收益。

## 实验与三轮复审

计划：[三轮复审与预登记](wsc-intervention-ablation-plan-2026-10-15.md)。材料固定，不重新生成更好的交接；原文、交接、原生工具、任务请求、路径、角色/顺序、模型和额度在每对条件中一致。

- 接受条件：原完整D校验 / 撤除fact_disposition / 仅撤除退休来源的新鲜度，6候选×3条件=18次判定。所有其他来源/结构校验保留，候选和来源哈希一致。
- 呈现条件：完整 `project_state` 与仅删 `declared_objective / declared_decisions / declared_constraints` 三字段。原始依据、执行信息、context_sources、任务项等不动。
- 六个短任务，各条件2观察，共24条独立轨迹。输出实际写入JSON决策清单；它们不是数据库代码修复或长任务完成的证明。
- DeepSeek Flash、thinking disabled、temperature 0、单路；每条轨迹最多4次请求，每请求2048输出；无HTTP重试。
- 这是受控的“自然交接＋D状态”组合消融，不能冒称当前自然语言生产入口的前后对照或A1胜负。

## 1. 接受条件：拒绝直接删除

| 候选类别 | 基线 | 撤除退休检查 | 仅撤除新鲜度 |
| --- | ---: | ---: | ---: |
| 正确纠正旧解释，2种声明形式 | 接受0/2 | 接受2/2 | 接受1/2 |
| 错误删除有效约束，2种声明形式 | 接受0/2 | **接受2/2** | **接受1/2** |
| 原声明不变 | 接受1/1 | 接受1/1 | 接受1/1 |
| 伪造不存在的来源 | 拒绝1/1 | 拒绝1/1 | 拒绝1/1 |

“接受更多”不等于质量更好。两种撤除都扩大了已知错误候选的接受范围，因此不并入。该结果也没有证明原检查能判断语义；它只能拦一类缺少手续的变化，而不能区分正确纠正与错误遗失。

证据：`_wsc_out/wsc-intervention-ablation-358/acceptance-results.json`。

修正版另建独立工作区：case-01等匿名路径；实际保存原要求/查询和schema/账目与旧报告/配置和失败记录；通过生产Read生成真实回执；24个发送体均核实调用与结果配对且正文未丢；产物名统一为当前要求的result.json。两臂交接仍是同一原产物，额度不变，24份输入文件全程未改。

## 4. 共同失败归因

失败场景：原始账目7+5=12、旧报告12，应交付验收记录；两臂均写了 `action=correct_report`，金额12和不发布均正确。实际只生成决策清单，没有证明旧报告被真正重写。

另外固定同一来源/路径/工具/问题，分别去掉整个状态块、再去掉交接，各2观察：两种参考均0/2，均输出相同错误action；共8请求。它说明这一失败在没有WSC状态投影和语义交接时仍发生，不能归因于本轮撤除的字段。基础模型对共同任务表述的理解仍未分离，不进一步把它认证为单纯模型缺陷。

## 5. 全局删除的反例与准入

用现有生产 `project_state` 和32,000字节来源内联预算构造一条长用户来源。准确约束位于原文末尾：`金额只使用整数分；禁止发布。`

- 来源进入deferred_sources，context_sources为空。
- 完整状态的declared_constraints保留准确约束。
- 同样删三个字段后，该约束从热投影消失；冷层存在不能补上当下可见性保证。

这是信息损失反例，不是付费模型失败。它足以拒绝把小任务中看似重复的字段无条件删掉。没有新增“语义等价判定”或新的条件分支来强行准入。

**准入结果：** 撤除退休校验拒绝；撤除新鲜度拒绝；全局删除三字段拒绝。当前自然语言路径已无完整D展开，保持现有行为。本轮生产改动0、默认改动0、长期旁路新增0。
