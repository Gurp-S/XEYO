## 结果与准入边界

原始来源、quote 与 scope 在专用生成接口中成为同一记录；编译到既有持久格式后仍由原 native Guard 校验。默认入口已接入，没有新 flag、持久化格式或迁移；没有重启现场 XEYO，所以源码默认生效不等于现场长会话已经重载。

本项收益是表示层消除独立 scope 数组的错配入口、缩小 schema。不是 Guard 判断语义，也不是任务成功率提升。本轮两域两臂均成功，没有证明 D 超过 A1，不能代替原228或多代验收。

## 结构根因与实际实现

原协议需要模型独立生成 decisions/constraints 与 phase_state.fact_scopes 的位置对应数组，已有真实生成出现长度不符。模型仍负责判断 scope；引擎只把同一记录无损拆回旧格式，引用/phase/退休事实/执行身份保护全部保留。错 scope 不自动补全，双权威拒绝，旧整体表示走原 Guard，不迁移旧存档。

实施前三轮复审见 `wsc-D-inline-scope-three-reviews-2026-10-14.md`。特别保留原始 wire ToolUse，错误续接不回放编译后的参数；正常提交才返回 native 对象。完整新 schema 进入原计数与容量准入路径。无额外提示句或历史原文块。

## 自己发现的失败与未解决项

初次291评测选用了没有安装私有tokenizers依赖的解释器，`context_token_measure`返回None，旧评测运输层索引失败，随后本轮驱动没有保存异常且假设已有首个请求，触发StopIteration。291的run-report明确calls=[]，没有外发或费用；原材料不删除。恢复此前私有deps后使用独立292，修复驱动先保存异常、零请求时不假定first存在；未重试任何HTTP。没有改项目或全局依赖，没有把估算换成虚假的精确计数。

本轮D_parallel排班及D_inline排班的objective仍夹入了“仅生成交接/不执行原任务”的控制请求用途；素材两例没有同样表述。即使实际文件成功，这仍是独立语义失败风险，不能因机械接受或产物成功关闭。来源正文进入上下文也不等于模型理解正确。

U2 epistemic、U3完整显式transition/fact版本关系、U4重要变化强制原anchor、U5语义支持边界、U6权威runtime phase registry保持未完成。scope同项只修生成表示，不等于U3/U6完成。原生全量生产renderer仍过重，不能把本轮native JSON热头当作生产薄层已达标。
