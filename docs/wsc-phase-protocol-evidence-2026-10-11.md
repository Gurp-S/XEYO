# 批次66：阶段声明协议、真实反控与主请求失败

## 结构性根因 / 规则 / 回归

旧引用校验只证明原文存在。当前阶段、检索来源及约束适用范围被混在一个平面数组，历史来源被保留后容易再次成为当前要求。

新独立协议 `synaptic/task_phase.py` 声明 `phase_state`：当前阶段ID、阶段来源、当前原文工作集、逐项引用作用域（task或phase）。模型判断语义，引擎只验证结构、唯一身份、来源、阶段基点。任务级事实跨阶段保持适用；阶段级事实只有该阶段为当前时适用。历史引用仍在原成功回执及冷对象，能够精确Read；不按关键词删原文。

重要修正：**来源的历史阶段和当下检索用途是不同概念**。历史来源可以继续供当前任务检索，其中可能有持续约束；源来自过去不能直接禁止读取。声明热原文带来源阶段信息，适用性由独立fact_scopes控制。

回归覆盖当前/历史作用域、长期约束、失败验收、重复及未知作用域、历史来源检索不自动激活其要求、退休引用不能通过最新回执别名继承、阶段切换不能仅用旧来源、允许新的真实文本/唯一非取消工具回执作事件来源、`@latest_user`锚定原用户而非后续“继续”、真实工具提交/文件持久化/重载、native与回退force及旧冻结头不变。

## 实施文件与当前接入边界

- 新独立 `synaptic/task_phase.py`、`memory/wsc_handoff_phase.py`。
- `task_checkpoint.py` / `task_handoff.py`：投影声明作用域，历史引用冷存，当前来源带阶段信息；阶段事件独立召回。
- `task_fact_sources.py` / `wsc_handoff_facts.py`：已退休的阶段引用不作为当前已提交引用供继承。
- `wsc_handoff_bindings.py`：携带已声明阶段基点，准确解析原用户别名，原回执不修改。
- `wsc_handoff_generation.py`：独立 `scope_protocol`参数提供实验schema；来源/目录参数错误现在是有界中性失败回执，不静默补默认参数；生成schema明确必填`context_message_ids`。
- 评测 `wsc_phase_review.py` / `wsc_real_task_handoff.py`新增协议入口，真实提交和独立作用域评分。

**阶段协议仍为离线验证阶段。** 曾暂接主query_loop要求阶段声明，但下文主请求失败后已撤回；普通TodoWrite schema不广告阶段字段、主生成不强制新协议。解析/投影支持显式新声明；不能把支持协议写成主模型已开始正确维护阶段状态。中性读取错误与必填来源schema进入现有生成路径；Compact/80/85、64次总读取、费用/容量边界不变，没有增加无收益的额外复核调用。
