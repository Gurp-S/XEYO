## 3. 收益（相对改前）

| 维度 | 改前 | 改后 |
|---|---|---|
| 跨会话记忆 | 子 Agent 候选永不过闸；主会话几乎不收割 | 收割标记 / 「请记住」进 `candidates.jsonl`，NightShift 以 ≤0.6 写入 topics + 索引 |
| 召回 | 仅靠 Grep；无 `last_used_at` | `Memory search` + 词法/置信度/近因排序；命中更新 `last_used_at` |
| 用户偏好 | `scope=user` 仍落在 workspace 目录 | `~/.xeyo/memory/user/` 跨工作区 |
| C2 默认 | 代码默认开，文档写关；证据未齐 | **默认关**；`XEYO_C2_GATE=1` 灰度 |
| 超长会话省幅 | 首压后 θ 卡死扩展 | `c2_extend_decouple` 默认开 + 更松的扩展闸（仍保守） |
| 摘要保真 | 每条硬 160 字均分 | 全局预算 + 错误/取值优先配额 |
| 尾部保留 | 按 6 **条消息**，并行工具易丢结果 | 按最近 **3 个工具成对轮** |
| 热路径 CPU | gate 开则每轮全量 deepcopy | 已压缩态可增量拼右尾 |
| aging vs C2 | 压缩后仍可能推进 frozen | `compact_cursor>0` 时跳过 aging 推进 |
| 运维/产品 | 无手动压；无记忆列表 | `/compact` + Header 按钮 + notes API |
| NightShift 锁 | 崩溃永久卡死 | 死 PID / 过期可回收 |

## 4. 开关速查

| 变量 / 参数 | 默认 | 含义 |
|---|---|---|
| `XEYO_L5` | `project` | 不跑每轮 v61 decide |
| `XEYO_C2_GATE` | **关** | `1` 时允许超长会话公式 C2 |
| `Params.c2_extend_decouple` | **True** | 已压缩后按 append 闸扩展，不等 θ 再返回 C2 |
| `Params.c2_extend_ratio` | `0.25` | 新区 ≥ 已冻区 25% 才扩展 |
| `XEYO_TOOL_AGING` | 开 | C0/C1 老化存根；与 C2 不同轮抢边界 |
