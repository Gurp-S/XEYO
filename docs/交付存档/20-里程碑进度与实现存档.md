## 二、已实现的关键能力

- **事件身份**：同 turn `session_id + turn_id + event_id`，SSE/JSONL/前端一致。
- **任务状态**：引擎权威 `SessionTaskState`，可 `task_state_snapshot()` 查询；Todo 不再是唯一事实源。
- **工作区隔离**：`WorkspaceContext`（contextvars）+ 权限上下文优先读会话 cwd。
- **审批模式**：`XEYO_PERMISSION_MODE=always/risk/never`（默认 `risk`）。
- **权限闭环**：`Write`/`Edit` 确认门 → `permission_pending` → 弹窗 / 微信 `/allow` `/deny` → `resolve` 恢复或拒绝；超时默认拒绝；同一 `request_id` 只处理一次。
- **远程对齐**：iLink/远程镜像权限与任务状态；本地桌面能为远程任务弹窗；pending 跨刷新保留。
- **提问挂起（AskUserQuestion）**：助手向用户提问（可带选项/默认值），turn 挂起等待作答；用户可以选项即点或自由输入；作答后恢复并把答案作为 tool result 交回模型；超时视为未作答。
