## 结论与边界

之前“去掉某类签名即完成去噪”的方案不治本：显示过滤和失败事件删除混在一起，短头可能来自信息漏失。本批改的是来源、身份、状态和保留契约；不以少行数或少 token 单独验收。

已续接两份未完工作：XEYO 同一会话里第 1/2 批去噪承诺，以及 Codex 原先的冻结期间目标状态更新、完成后折叠吸收。新增行为默认关闭；未修改线上设置、线上冻结头、会话既有行。

不能据此宣布整个 WSC 已完全治本：本批没有调用真实模型，未测白跑率或厂商缓存命中；旧记录缺少可靠验收状态时仍为未知。有限窗口也不能无限保留不断增长的全部用户文本。

## 修复前三问

**结构性根因**：同一份历史同时被当作存储、活跃目标和显示摘要；正文签名又兼任事件身份和删除依据；冻结头的状态时钟跟着折叠时钟走。首次折叠还漏接完整请求软水位。

**结构规则**：原文无损留存；人类文本保留和任务终态分离；绑定目标来自 GoalStore；执行身份来自工具、机器分类和完整声明参数，正文不参与新身份；来源组贯穿去重、PIN 绑定和跨轮生命周期；未知保留，不由显示规则宣告成功。状态变化先持久化后追加，不能可靠恢复时阻止不一致发射。

**回归**：改变诊断正文不能改变机器失败身份；空正文仍保留失败；成功回执引用失败文本不变成机器失败；不同目标/命令不误并；同 id 不同参数降为未知；多个失败没有单一调用身份时不误并；极小显示预算不裁掉完整计划；用户字面 XML 不当成注入删除；暂停/完成、重启、去重、开放工具对、磁盘失败、缺失/损坏状态账本和不可读绑定均检查。

## 已实施

1. `memory/wsc_goal_events.py`：独立的代际状态事件账本，记录源位置、源摘要、goal_id、revision、status。只追加，工具对未闭合时延期；同状态去重；重启按原位置恢复。完成/放弃的文本统一为空，真正折叠后不再重发已吸收事件。账本损坏或已提交账本丢失时停止发射，避免降级破坏此前前缀。
2. `memory/wsc_goal_source.py`：绑定存在但不可读、绑定目标缺失，均为未知/读取失败；只有实际没有绑定才返回无绑定。防止把读取失败误当目标解绑。
3. `synaptic/seeds.py`：显式空 `unresolved_idx` 是有效权威结果；旧调用也委托同一个 freshness 生命周期，不再重算第二套。区域外错误不能偷渡进折叠头；删除本模块无调用方的旧成功词表及重算副本。
4. `synaptic/failure_facts.py`：新增 `XEYO_WSC_FAILURE_FACTS`。类别采用机器 `error_kind/status`，完整调用参数参与身份；短路径和正文不决定身份。未知调用、冲突调用 id、多结果消息保留逐消息来源。限制事实亦按工具、类别、声明目标分组。无法证明当前项目缺陷时显示为失败记录，不自动派生修复目标。
5. `synaptic/pin_sources.py`、`pin_render.py`、`lifecycle.py`：结构化来源组直接绑定全部实例；跨轮比较使用同一身份摘要及 schema，覆盖解除时依靠现有同调用成功证据。新卡面不重复搬运错误叙述；`WORKING SET.related_errors` 的重复显示由独立失败通道承担。原始卡与节点仍可回读。
6. 原 `XEYO_WSC_USEFUL_SIG_GATE`：只能省略诊断摘录，不能删除失败 PIN 或来源。删除“出现省略号即无信息”的判据。新失败事实旁路完全绕过这套显示签名判据。
7. `synaptic/path_origins.py`：候选来源限定为工具声明，未完成 Bash 调用也保留命令点名路径。正文例子不成为声明目标。`origin=tool_argument/command_mention` 明确证据层次，均不冒充文件存在或实际文件操作。
8. `synaptic/requirement_floor.py`：新增 `XEYO_WSC_REQUIREMENT_FLOOR`。按角色及结构化 note 元数据识别声道，完整用户文本进入历史事实区，不猜任务过期；原样保留字面标签与长计划。请求投影不再从最早请求派生目标。超过摘要预算的真实成本明确入账，不静默摘录或关闭原话通道。
9. `memory/wsc_first_admission.py`：已有正数软水位也约束首次普通折叠；未知/不足完整请求 token 时暂缓。现有 HardTop 强制路径继续绕过软水位。不擅自修改线上阈值。
10. `evals/wsc_goal_event_replay.py`：真实 GoalStore + 生产投影链的非空状态变化验收。原无绑定样本的“没有状态也算状态折叠通过”已移除，标成未演练。

`XEYO_WSC_FAILURE_FACTS` 含不可变状态/冷层契约；`XEYO_WSC_REQUIREMENT_FLOOR` 含请求投影及相同契约。开关全部登记在环境隔离表。新逻辑进入独立模块，接线保留默认行为。
