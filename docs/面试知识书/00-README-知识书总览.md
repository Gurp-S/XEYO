## 已生成分册的核心论点（速查）

### 第一册 · 运行时内核
- `QueryEngine`（状态容器 + 依赖注入）/ `query_loop`（无状态 async generator）/ `TurnRunner`（扇出）**三层切开**，引擎不碰传输。
- 并发提交用**布尔标志快速失败**（不是 `asyncio.Lock` 排队）；`finally` 复位**不等 finalizer**。
- 慢订阅者**直接踢掉**（`maxsize=512`），不阻塞生产者。
- **`_memory_index_live_enabled()` 恒 `False`**（事故退役）——「讲清一项功能为什么被下线」是最好的面试素材。
- 20 个引擎事件构成跨进程契约；SSE 序列化只有一处（`chat.py` `_producer`）。

### 第二册 · 模型与上下文工程（**全书最高价值**）
- 模型层抽象只有**一个方法**（`stream`）；provider 选择是 **`if/elif` 而非注册表**（纠正「可插拔注册表」误述）。
- Anthropic **必须原生**（6 条协议差异，核心是 thinking 的**不透明签名**回传）。
- **全仓无显式 `cache_control`**——缓存靠「**前缀逐字节不动**」的结构保证，不靠标记。
- 上下文工程三句：**静态前缀只放不变的、易变内容全部尾插、注入有硬预算与硬准入**。
- T_now：**20 块登记表** + **伪造 tool 对（`xeyo_env_notice`）**承载 + 三类语义（directive / event / inventory）决定预算待遇。
- **⚠ 认知纠正**：env_channel 被结构类 4xx 拒绝时回退 **`skip`（不是 `legacy`）**；状态码集合含 **405**。

### 第三册 · 工具系统
- 25 项工具（权威源 `catalog.py:261`），**启动期与 `meta.py` 交叉断言**。
- **工具面会话内冻结**（schema 缓存），会话内启停走 **`Mcp` 网关单通道**。
- schema **手写**（因为 `description` 是模型可见文本）。
- 并发：**只读并发 / 写串行 + 读写锁**，分区判定与加锁判定**同源**。
- **⚠ 命名债**：`exec_channel.py` **不是**执行通道（它是容器感知观测原语）；真正收口在 `ToolRegistry.run:296`。
- 容器路由背后的**真实并发事故**（`os.environ` 覆盖 → ContextVar 隔离）是极好的 STAR 素材。

### 第四册 · 安全与一致性
- 三态枚举实际在 `filesystem.py:32-35`；**11 个判定点**（不是「8 支」）。
- **未知工具兜底 = ASK**（fail-closed）。
- **指纹不含参数**（只认身份 → 注入免疫）；`v2:` 前缀使 v1 凭据自然失效。
- **收紧即时、放宽延后**；危险操作 TTL 更短（60s vs 180s）。
- **⚠ C-07**：`rm -rf .` / `rm -rf *` **不被硬拒**（正则锚定方式所致），是真实可复现缺口。
- **⚠ C-05 + D-4（亲读裁决）**：transcript 归档方向写反（**实际只保 1 代**）；writer 批次失败**仍推进 `_written_seq`** → `flush` 假成功。

### 第五册 · 记忆与知识
- **明确不上向量检索**（可复现 grep 证据 + 三条理由 + 对照实验 `evals/retrieval_bench.py`）。
- 检索 = 关键词 + **CJK ngram（不用分词器）** + sqlite 结构化过滤 + 重排；`search.py:1` **禁止调模型**。
- **⚠ `topic_filename` 忽略 scope/applies_to** → 同 type+title 覆盖（**数据结构级根因**）。
- `may_resurrect` **恒 False**（遗忘不可逆）；agent 自收割 confidence **封顶 0.6**。
- **仿真台**：决策 / 状态 / 成本 / 质量 / 缓存 四模型；**Q = fidelity × visibility**；标定**只写 overlay**。

### 第六册 · 扩展与多智能体
- MCP **只有 stdio**（类型层面约束）；退避**随稳定性重置**；`start()` **绝不抛异常**。
- 网关身份**「查出来、不听出来」**；不绕权限。
- **⚠ C-06**：`reconcile` 的幂等表**无 session key**（与容器路由事故**同类根因**）。
- **⚠ C-04（P0）**：`run_task_batch` / `prepare_for_resume` / 分解链 **无产线调用方**（精确接线表已给）；`Task` / `toposort` / `build_tool_whitelist` **已接线**。
- 子代理：**store 独立 + abort 共享**；消息 **park 不打断**；结算 **单一槽 + 三租户分发**。

### 第七册 · 一致性与服务
- rewind **三代并存**：v2 = **降级路径**（`service.py:266`）/ v3 = **主路径**（`hotpath.py:328`，GUI 对接）/ v4 = **索引对账**（`index.py:573`）。这是「有意识的兼容债」，不是没清理。
- 快照是**内容寻址 blob（SHA-256）**+ 每轮 COW 检查点（本体只是 `[[path, hash]]` 清单）；冻结时机 = **用户消息发出、模型动手之前**。
- **`anchor` 端点**是最值得讲的小设计：把「这个状态有用」这个人类判断，变成 **GC 的可达性输入**。GC **默认 dry-run**（唯一不可逆删用户数据的后台任务）。
- **CORS 显式白名单 9 项**（纠正「可能是 `*`」）+ **loopback 门禁**；`workers=1` 是**架构约束**（引擎态在内存）。
- ⚠ 认知纠正：`yield_to_human` 在 **`goal_round_driver.py:164`**（人类消息让位），**不在** `session_presence.py`（后者管多会话文件冲突）——**同名不同责**。

### 第八册 · 界面与分发
- TUI 时间线**物理切两段**：`<Static>` 冻结区（只渲染一次）+ 实时区 —— 这是**性能正确性问题**，不是代码组织。
- **S34 slash 单一事实源在 Python**：`registry.py` 定义 → 导出两份 TS manifest → `check.ps1` 的 `--check` **漂移即提交失败**。
- GUI 布局档位写 `html[data-pane-layout]`，**由 CSS 布局 → 切档位零 React 重渲染**；SSE 靠 **cursor 续订 + 60s 空闲看门狗**。
- ⭐ §21.4 是全书最好的**事故 → 结构性修复**案例：薄壳 venv（launcher 指向构建机）+ `pyvenv.cfg` 的 `home=.` 坑 → **构建期 4 条硬断言**。
- ⚠ C-16 定论：**引擎事件 20 个**，GUI 基本全覆盖，TUI 显式仅处理 `permission_pending`（其余靠 `xy` 透传）；**新增事件 TUI 静默不跟进**。
- ⚠「换入口丢数据」= **换库不是删库**（IndexedDB 按 origin 隔离，dev `5173` vs release `tauri.localhost`）。

### 第九册 · 评测与工程
- 成本链：**按 `vendor` 计费（不是通道）** → 三级归因（base_url 主机 → 模型名前缀 → 通道）→ 能拿厂商就厂商、否则本地。
- ⚠ **N9-1**：`_fetch_deepseek` 硬编码 `vendor_ok=False` → **「厂商权威用量」只对 OpenAI 通路成立**。
- 评测分界：**能穷举验证的不调模型**。BFCL lite **100/100**（¥0.0433，输入缓存命中 **96.9%**）/ HumanEval **156/164** / MBPP **97/100**；离线多任务门 **112/112，¥0**（6 组：6+28+11+6+5+56）。
- `retrieval_bench` 的分层结论：**code hit@k 1.0 / notes 0.4** ⇒「向量该上的地方是 notes，不是代码导航」。
- ⚠ **`L404/L475/L543` 是漂移类别代号，不是行号**。
- `changedetect` **L0（1 字符灵敏）/ L1（分支级）/ L2（必须自报 MDE）**；⚠ **N9-5 成本口径双轨**（评测用新价、账本用旧价）。
- ⚠ **N9-6（本次实测新增发现）**：4 个诚实度守卫 docstring 写「默认关」，实现因全局升格谓词默认 True 而**实际默认开**。
- ⚠ **N9-4**：可观测性产物**第一消费对象是模型不是人**（`LoopLedger.render()` ≤3 行注入 prompt）；`prof_stats` / `stage_clock` / `process_ledger` **无实时消费方**。

### 第十册 · 容错与稳定性
- 四类刹车 + 恢复轴：**中止（单向级联）/ 预算（3 轮宽限窗）/ 重试（`not saw_any` 不重试）/ 重复抑制（三道防线，全部「永不拒执行」）**。
- **`not saw_any`**：模型已吐部分流则**绝不重试** —— 宁可失败，不制造「同一轮两版历史」。
- **收尾窗内长命令自动后台化**：信号是事实（窗口开了），动作在执行层（引擎理念）。
- F013 续跑指令**投影-only + 轮末即清**，防**跨任务锚定**（与 L543 同族事故）。
- 恢复两层：运行期 `query_loop.py:218` / 重启后 `hydrate.py:73`；⭐ **只读工具 `NOT_STARTED`、其他 `OUTCOME_UNKNOWN`**（写操作不能假设没发生）。
- ⚠ **N10-1（修正既有叙述）**：后台 job 的「**事实无超时**」**已被修复** —— 现默认 **6h 上限**（`JOB_NO_TIMEOUT_MS`），两路径均执法。C-09 的「绕权限/rewind/审计」部分仍成立。
- ⚠ **N10-2**：预算**墙钟 / USD / token 默认全关** —— 开箱硬顶只有 **256 轮 + 64 次工具调用**。

- **3 个每轮新建的控制器**（`streamDrain` / `streamToolSettle` / `usageAccumulator`，`streamSendSlice.ts:1059/550/372`）——**每次 `sendMessage` 按 session `new` 一个**，不是全局单例
- **3 个共享 helper**（`preStoreHelpers` / `spaceHelpers` / `streamHelpers`）

**划分标准是生命周期**：切片装长生命周期状态（会话列表、UI chrome），控制器装「这一轮」的临时对象（排队、结算、用量累加）。**把控制器做成全局切片，并发两轮时会互相踩**——这是能讲出「所以」的那种细节。

### 3. `gui/src` 292/292、`tui/src` 29/29、`gui/src-tauri/src` 3/3 全部落点

§`09` §23.4 以**清单级**（按目录分组列名，不逐文件讲解）收录其余 200 个文件。**这一步的收益不是内容增量，而是把「覆盖」变成了一个可机器验证的客观标准**——第四轮那个洞之所以要补，不是因为它藏着答案，而是因为**只要有洞，就无法证明洞里有没有答案**。

### 4. 本轮仍然不做的

- **不给组件写职责说明**：清单里 63 个 `components/*.tsx` 只列名。给每个面板编一句「它负责显示 X」是**填充而非信息**，面试不会问。
- **不声称「讲清了」**：覆盖率 100% 只等于「没有文件被完全遗漏」。
