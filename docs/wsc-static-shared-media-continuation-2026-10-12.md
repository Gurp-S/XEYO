# 批次113：优先实现主Goal，混合结果的媒体按源消息保留

用户顺序已固定：优先Goal，其他bug记录后置，见wsc-post-goal-bugs-2026-10-12.md。当前只推进T18候选的实现范围，不修改UI或删除流程。

原边界：迟到消息同时携带多个工具结果及共享内联图片，候选supported拒绝，因图片无法确定属于哪个调用。主Goal要求保全并可续接，而不是猜归属或一直停止。

实现：复用原消息及调用身份，图片保持原消息中的原块/原位置。迟到结果消息存在图片时，同一消息内全部对应结果和调用统一投影为记录事实，避免把共享图片交给厂商的原生tool_result编码而隐式归属到某一个调用。迟到调用标arrival=non_adjacent，同消息其他调用标same_source_message，不假称其迟到；不赋予图片调用归属。原始存储、时间线和调用入参不改，也不模拟重执行。

只改session/late_result_projection.py。原有未知/重复/缺失身份拒绝保留，外置或非共享支持的媒体仍拒绝；默认开关未改变。未将候选默认关闭这一缺口隐去，未宣称T18完成或收益已证明。

静态核对合同（没有执行）：迟到+相邻结果+共享图片时，两条对应调用均改为事实，源结果消息内不留下原生结果与共享图片混配；图片块原样保留；无图片路径保持既有投影；重复/未知身份及不支持媒体仍阻断。测试0、编译0、API0、费用0，git diff --check通过。真实厂商、主模型使用、冻结代迁移及默认接入证据仍开放。
