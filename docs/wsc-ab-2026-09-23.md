## 2. 机制层：WSC 投影 vs 三条对照臂（【评测-离线】47 会话 / 29 段带外部真值，零 API）

裁定文件：`_wsc_out/qa_judge_evidence_final/wsc_qa_report.json`（含判据脚本 sha256、Wilson 95% CI、`gate_eligible` 与单会话占比防偏置位）。
四臂：**wsc**（线上投影）／**nocompress**（原文全量＝上界）／**empty**（空投影＝下界）／**hostile**（对抗乱序，防"任何文本都能得分"）。

| 机械判据 | wsc | nocompress | empty | hostile |
|---|---|---|---|---|
| V1 用户目标原话可见 | **95.7%** (45/47) | 100% | 0% | 4.3% (2/47) |
| V2 每条硬约束可见 | **100%** (35/35) | 100% | 0% | 0% (0/35) |
| V3 未解决失败的**原文现场**可见 | **71.1%** (128/180) | 100% | 0% | 5.6% (10/180) |
| V4 未解决失败的**现场文件**可见 | **100%** (69/69) | 100% | 0% | 0% |
| E2 最终轮历史错误仍可见 | **71.1%** (128/180) | 100% | 0% | 5.6% |
| R1 同根因再次失败（行为，非投影质量） | 22.0% (42/191) | 22.0% | 22.0% | 22.0% |
| R3 失败后原样重跑同一条调用 | **0%** (0/163) | 0% | 0% | 0% |
| I1 无新信息轮 / I2 白跑已知失败 | **0 / 0** (0/94, 0/47) | 0 | 0 | 0 |
| V5 最近写过的文件 / V6 未完成 TODO / A1–A4 结局类 | **n=0，测不出** | n=0 | n=0 | n=0 |

**能说什么**：硬约束与目标原话**零损失**（100% / 95.7%，与不压同分）；空投影 0%、hostile ≤5.6% ⇒ 判据有判别力，不是"随便给点文本都过"。
**不能说什么**：V3/E2 的 71.1% 是"未解决失败的原文现场"——**这就是压缩真正付掉的那 28.9%**，别把它说成"信息全在"；
R1/I1/I2 三臂同值 ⇒ 它们是**任务行为**指标，不能用来说明哪种投影更好；V5/V6/A 类在 dev 语料上分母为 0，**没有结论**。

**同口径的体积代价**（【评测-离线】三臂逐枪实发头，会话 `qawa1w` / `tgbg36`）

| 投影策略 | 实发头中位 | 其中索引 | 整份发射中位 |
|---|---:|---:|---:|
| 生产档（冻结头，只由折叠事件推进） | **1,633 / 2,737** tok | 0（索引折进头） | 24,592 / 67,162 |
| legacy（每枪重投影） | 6,267 / 8,694 tok | 3,838 / 4,868（占头 61%/56%） | 11,226 / 14,645 |

⇒ "头只由折叠事件推进"这一条把**头**从 6~9k 压到 1.6~2.7k（约 1/4），代价是交界之后全量重发（整份发射反而最大）。这正是 θ=1 经济闸要管的东西。

## 5. 撤回与判死（这轮亲手推翻的自己的数）

1. **撤回**："M2 信息在场率 WSC 10.9% vs C2 原生摘要 2.0%（5.4×）"。查出处：10.9% 在 `_locator_rows.out` 里是**某会话某点 R2 重复行占热层比例**，不是在场率。→ 用 §2 的四臂表替代。
2. **判死**：让 reducer 猜"请求已完成 / 约束已失效"（无事件来源）；尾部 token 上限；合成孤儿回执；工作集原地刷新；信息型 θ。
3. **作废**：一切按 `calibration_events.action` 分组的折叠数字（含"折叠当枪重填面 71.1%，n=38"）。
4. **口径冲突不许并排**：V1 stale（行 5.0%）与 V2 stale（事后 0.75）是两把尺。
