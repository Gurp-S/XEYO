# D 续接、接口与 API 用量证据（253–257）

方向不变：优化 D 的语义交接、精确冷恢复和失败续接，以 A1 为对照，保持确定性层薄而可靠。质量优先于费用。以下均为离线真实种子加受控后续事件的实验，不是新生产现场压缩；新候选没有并入生产。

## 253：一句语义内容范围的消融没有证明收益

共同 full-state / optional observations 接口下，对比原接口 D_slot 和只新增“交接内容范围：继续当前工作所需的结果事实、具体值及其依据。”的 D_semantic。两份真实种子分别维护自身后续状态，A1 单列。

第2代接受：A1 2/2、D_slot 1/2、D_semantic 0/2。语义句候选仍出现非法状态、scope 及事实退休声明错误；没有稳定行为收益，该句不准入，不继续靠重跑寻找正例。失败后保留原文产生的冷回答不能归因给未接受的新交接。

第3代 A1 两例接受，但整个对照在官方 402 时停止。35 次请求、34 份 usage，观察到的估算费用 ¥0.72809152，另保留无 usage 请求 ¥0.16913000 的保守预留；未把未知费用清零。6 个分支 stop/restart 证据保留新增事件、pending、上次合法热头和不可变来源 seal，不把不完整链拼接为完整排名。

旧任务事实退休失败的离线归因：模型选择退休的部分项不属于旧 task-scope 可退休集合；Guard 拒绝正确。结构性问题是声明接口暴露的引用范围大于合法事务范围，而不是凭关键词认为自然语言约束已失效。

证据：`_wsc_out/wsc-D-semantic-ablation-253/`，含 preflight、原始请求/响应、stop-recovery-proof.json 与源码快照。

- 不能将无答案/截断判为所有语义字段都错误，也不能用模型内部思考片段当作已完成答案。不能由此宣称开启 thinking 就解决问题。

## API 节约执行边界

厂商 usage 是实际命中证据，以下费用按既有估算费率 miss=¥2/M、hit=¥0.04/M、output=¥8/M，不当成当前官方发票或余额。

| 轮次 | usage / 请求 | hit | miss | 输入命中率 | 输出 tokens | 估算费用 | 输出费用占比 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 253 | 34/35 | 460,288 | 78,664 | 85.40% | 69,044 | ¥0.72809 + 未知预留 | 75.86% |
| 254 | 41/41 | 383,104 | 166,884 | 69.66% | 78,022 | ¥0.97327 | 64.13% |

255开启新消费模式的首请求命中约0–11%；后续许多逻辑续接命中较高。模式、工具定义和新分支均可能改变有效前缀，但仅凭 usage 不能证明是其中哪一个造成服务端冷缓存。[DeepSeek 官方规则](https://api-docs.deepseek.com/guides/kv_cache/)要求匹配已持久化的完整前缀单元，并不保证100%命中。

从用户最新要求开始固定执行：

1. 正确性和任务质量先于成本；不删必要信息、不降低验收、不压缩输出额度来制造省钱。
2. 已付费 request/response 优先离线利用；只有新的逻辑请求才发送，未知费用继续保留，HTTP重试为0。
3. 同分支保持工具、模型模式与请求前部稳定；实验需要改变时单列条件，不能为了缓存混淆对照或改冻结前缀。
4. 不发送纯预热请求，不假设未来命中作为准入依据；按实际 hit/miss/output 记账，余额不足停止并通知。
5. 去掉没有证明收益的候选后续付费支线；只付费回答明确未解决的问题，不重复完整长链寻找漂亮结果。
6. 继续使用完整来源、相同质量门槛与等额对照；更多输出/请求额度如确有必要，单列协议变更，不抹掉旧失败。
