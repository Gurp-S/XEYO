# WSC 335：交接回查与冷入口精简，实施前三轮复审

本轮保持自然语言交接为主，复用现有来源目录、精确范围读取和原生 Grep/Read。没有子代理，没有新模型 Judge，没有 HTTP 重试。原始前缀在两次显式折叠之间保持字节稳定；已有发布代不迁移。

## 第一轮：根因与最小职责

源码缺口：自然语言生成器只有一次无工具调用；即使完整来源仍在，交接也无法回查上一代遗漏的信息。发布层同时展开压缩输入、原始封套、定位目录三个长路径；目录保存身份和范围，但没有内容发现说明。

修改：自然语言生成复用 HandoffCatalog/HandoffSource，仅查询捕获的不可变来源；不暴露 TodoWrite 或任务执行工具。冷目录首行保留两个完整视图路径、记录数及搜索/读取接口事实。新热头只保留目录入口和必要媒体入口，交接正文不裁剪、不去重、不做语义重写。机械来源身份不等于语义支持。

## 第二轮：状态、预算与失败边界

回查沿用每请求容量校验、输出上限、流关闭计费、调用身份唯一性及请求配对。最多六个模型请求、64 次读取、48KB 返回；达到上限不安装半成品，不自动重试。生产额外请求与读取计入原会话预算；每次请求前校验控制和来源版本。无来源的直接摘要调用保持原单次方式。

生成失败只保留旧视图及完整未折叠增量；预算、中断、来源变化和发布错误不伪装成可续接的模型失败。引擎不根据普通文本解释取消、重开或覆盖。

## 第三轮：因果与准入

先用 307 两份真实会话及完全相同的既有交接产物，在相同路径比较改前/改后生产发布。只允许入口变化；正文、尾部、原文封套与媒体不变，目录实际 Read/Grep 可恢复，折叠间及重启前后稳定。

再预登记 DeepSeek Flash 同源多代对照，各臂使用自身上一代输出，覆盖 1/3/5/10 代、重启、迟到旧结果、暂停、完成、重开、范围及文件版本变化。另用故意遗漏且必须回查的冷证据场景区分需要识别、发现、精确读取和实际使用。失败样本保留；协议模拟与付费行为证据分开报告。请求单路、单次上限 2.5 元，未知 usage 保守预留；沿用全局账本。

准入：机械契约与冻结前缀通过；同产物无语义信息删除；任务、约束、状态和具体值无退化；回查带来的请求和费用完整报告。不能用 token 下降抵消质量下降；若行为对照不通过，不据离线绿灯声称质量已通过。自然语言整体默认路由是否切换仍需整体质量门槛，本轮不替代该验收。
