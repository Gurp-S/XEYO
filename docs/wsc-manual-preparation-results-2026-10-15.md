# WSC 333：合并手动压缩的公共准备流程

本轮不使用 API。D 与自然语言手动压缩共用预算初始化、执行上下文绑定和系统上下文构造；生成/声明提交与自然交接发布仍各走原有流程。生产源码直接接入，无新增模块、开关、提示词或运行组件。

## 三轮复审

1. **根因与不变量。** `engine/manual_compaction.py` 的两种模式重复维护同一请求准备流程，已经发生配置回退差异：显式 `max_budget_usd=None`、旧配置 `max_budget` 有值时，自然语言分支跳过旧配置而使用环境值。相同手动操作应由同一个入口解释预算配置，不能由生成表示方式决定。
2. **状态归属与时间顺序。** 来源持久化仍早于生成和折叠；工作区、会话及权限由原 ExecutionContext 管理。公共准备只在需要生成时发生，短历史、提前取消、D 无需刷新时不重置生成预算。正常请求保持各自原有的准入、声明提交及发布顺序，不强行合并不同的交接产物。
3. **最小实现与验收。** 把原 D 的预算回退及公共准备留在 `compact`，自然语言分支改为接收已构造的 system。复用既有预算检查，不新增策略对象、通用框架或旁路开关。验证六种预算配置、两种上下文来源、两种模式，以及早退和上下文释放；普通真实来源做前后请求对照。

## 复现后收紧的预算边界

零预算实验发现自然语言手动压缩设置了 `usd_limit=0` 仍会调用固定生成器。`prepare_next_turn` 并不代替费用/token 用量检查；D 的下游交接准备有该检查，自然语言分支缺少。

因此公共准备完成后统一调用已有 `wsc_handoff_budget.check_usage`，在分发生成路径之前执行。零预算返回已有 `budget_usd`，不生成、不推进游标。D 原下游检查保留，因为它也服务其他调用入口和后续工具准入。

该变化有意将预算拒绝提前到公共入口；预算拒绝不再进入各自的首次 turn 分配。正常预算路径的请求和用量不变。本轮没有重定义 BudgetTracker 的阈值或 reset 规则。

## 源码变化

- `python/engine/manual_compaction.py`：147→131 行，净减少 **16 行**。
- `reset_for_new_submit`、`build_system`、执行上下文 `evolve` 调用位置各从 **2 处→1 处**。
- `_semantic_compact` 接收公共入口生成的 system，不再自行重置预算或重新构造 system。
- 自然语言方法整体默认关闭的准入状态不变；D 与自然语言真实手动入口均使用该公共准备流程。

## 测试和对照

新增 `python/tests/wsc/test_manual_handoff_preparation.py`，29 项覆盖：

- 新预算优先、`None` 回退旧预算、旧预算缺省回退环境、明确零预算。
- 无已有上下文/已有上下文，保留会话、工作区、权限和 runtime，清空旧 request/projection 身份，退出后恢复外层上下文。
- 短历史和 pending stop 不构造请求、不重置已有预算、不改变来源。
- D 不需要新交接时不初始化生成预算。

修改前按正确错误协议复现为 **4 failed / 25 passed**：预算回退和零预算各在两种上下文来源下失败。候选专项及既有自然交接入口共 **48 passed**；接入后九个相关文件共 **100 passed / 0 failed**，覆盖交接事务、取消、来源变化、生成失败续接、多代发布中断、冻结头恢复等。这不是全仓库测试。

初次测试 `before.xml` 的六项失败中，两项是夹具错误地期待 `handoff_model_budget_exhausted`；核对既有 D 合同后改为 `budget_usd`。最终反例口径以 `before-corrected.xml` 的四项为准，原报告保留。

同源离线对照使用 307 的两份真实历史，1,647 / 133 行，各走 D / 自然语言手动入口，分别比较修改前与候选，共四组：

| 对照项 | 四组结果 |
|---|---|
| 实际构造的完整模型请求及工具 | 全部一致 |
| 空输出后的结果/错误 | 全部一致 |
| 调用轮数、tokens、预算限额 | 全部一致 |

固定生成器不返回交接正文或声明，明确测试空输出路径；D 为 `handoff_declaration_missing`，自然语言返回保留来源的 `semantic_generation_empty`。离线模型容量设为 2,000,000，仅为验证请求组装；这不是厂商真实容量或模型质量实验。实际冷召回、语义正确性及任务成功不在这组对照内，`semantic_quality=null`。
