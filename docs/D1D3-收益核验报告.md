## 三、收益边界（诚实口径 —— 这段比数字更重要）

**D1 的收益是条件性的**：只有在"引擎的观测面 ≠ 模型的工作面"时才兑现。

- **默认产品路径（GUI，宿主工作区）：收益 = 0**（行为字节级等价，用 108 例回归证明）；
- **兑现条件**：工作面不在宿主文件系统——容器路由（今天）、WSL / 远程 / 沙盒工作区（可预期的下一步）。
  这些路径今天就能被用户触达（`XEYO_DOCKER_CONTAINER` 是 bash/job 工具实际读取的路由，
  不是评测专属代码）。
- **它的性质**：不是"为提分而改"，而是"引擎不再断言自己观测不到的事实"这条信息纪律的补洞；
  代价≈0（多一次 ContextVar 读取 + 原有 Path 调用）。
- **尚未修的部分（已知）**：产物路径是**目录**时仍报"不存在"（旧语义，未改）；绝对路径的
  解析仍沿用 `Path(cwd).joinpath()`（旧语义，未改）。这两条不在本次范围。

**D3 的收益有一个真实产品路径**：收尾窗口不只在"墙钟武装"时出现——
`prepare_next_turn()` 返回 False（**轮次/工具调用配额耗尽**，产品会话默认 256 轮）同样进入
`forced_wrap_up`。所以"窗口内新增长命令不再吃掉落盘时间"在产品长会话里同样生效。
墙钟武装（`XEYO_WALL_HARD_STOP`）只是让窗口在时间维度也可触发。

**D3 的防误伤设计（已实现并测试）**：只在"窗口剩余 < 120s 或未知（配额型）"且"命中长命令族"时
才立即后台化；剩余充裕时不动——保住"最后一步长命令能在窗口内跑完并出产物"的路径。

## 四、无法离线测的部分（必须说明）

**任务级转化率（分数收益）无法离线测**：D1/D3 是否真的把某道失败题救回来，只能在真实跑批中
观察（P3 小样本 20 题 ≈ **¥6~8**，新价；P5 全量 89 ≈ **¥28**）。
本报告的收益全部是**机制级**指标（误导事实 1→0、控制权 1.69s→0.01s），不是分数。

## 五、裁决

| 改动 | 裁决 | 理由 |
|---|---|---|
| **D1 `da8a990`** | **保留**（可随时回滚） | 默认路径零代价、修的是"引擎断言不可观测事实"这条通用纪律；兑现条件（非宿主工作面）今天可触达、且是后续 WSL/远程的必经之路。**若严格按"当前产品路径必须有收益"裁定，它今天收益为 0——可以回滚，见 §6。** |
| **D3 `5f61b21`** | **保留** | 机制级收益实测存在，且收尾窗在"配额耗尽"这条产品路径上就会出现；防误伤边界已实现并测试 |
| D2 完成门控 | **暂不落地** | 体量大（query_loop 巨石，~400 行）；应先做 P3 小样本量出"机制兑现率"再决定（¥6~8） |
