## 二、三条经验律（全部从这 20 条数据里测出来）

### L1 — harness 律：同模型换 harness 值多少分

官方有 4 组干净配对（同模型、同推理档位、只换 agent）：

| 模型 | harness 对比 | Δacc |
|---|---|---:|
| claude-opus-4-7 (max) | claude-code vs terminus-2 | **+2.8pp** |
| gemini-3-pro (high) | gemini-cli vs terminus-2 | **−8.1pp** |
| gemini-3.1-pro (high) | gemini-cli vs terminus-2 | +0.2pp |
| gpt-5.5 (xhigh) | codex vs terminus-2 | **+5.2pp** |

**Δacc 均值 +0.03pp，sd 5.0pp，极差 −8.1 ~ +5.2pp。**

两条推论：
1. **terminus-2 与厂商原厂 harness 平均打平**——"谁是更好的 harness"这件事在数据上没有系统方向。
2. harness 是 **±5pp 级**的影响，不是 ±20pp 级。任何超过 10pp 的口径落差都不能归因于 harness。

### L2 — 复现律：同配置重跑的纯噪声

官方数据里就有两组同 (agent, model, effort) 的重复提交：

| 配置 | 两次 acc | Δ |
|---|---|---:|
| gpt-5.6-luna / codex / max | 71.2, 75.7 | **4.5pp** |
| gpt-5.6-terra / codex / max | 74.4, 78.4 | **4.1pp** |

**同配置重跑就能差 4pp 以上。** 这是任何单次跑分预测的噪声地板（折算 sd ≈ 2.1pp）。

### L3 — 口径律：pass@5 ≈ acc + 15pp，反推题目难度结构

`pass@5% ≈ 38.56 + 0.679 × acc%`（R²=0.754）。用 Beta(a,b) 拟合每行的每题成功率分布，得到难度三带：

| 档位 | 必失败 (p<0.2) | 掷硬币 (0.2~0.8) | 近乎必胜 (p>0.8) |
|---|---:|---:|---:|
| 头部（fable-5 / claude-code，83.8%） | 8% | 16% | 76% |
| 中部（opus-4-7 / terminus-2，66.1%） | 20% | 27% | 53% |
| 尾部（glm-5.1 / claude-code，58.6%） | 31% | 22% | 48% |

外推到 90.3%：**可作用面 ≈ 15.4 题（17%）**，其余 ~74 题对任何 harness 都近乎必过或必败。
→ 若 harness 把这 15 题的成功率平均推动 ±0.3，总分只动 **5.2pp**——与 L1 实测的 5.0pp sd 自洽。**系统是闭合的。**

## 三、XEYO 的定位与预测

定位全部来自机制层，不引用任何本地跑分：

1. XEYO 在 TB 下以 `XEYO_BENCH_MINIMAL` = **bash-only** 运行 + `docker exec` 容器路由，**形态与 terminus-2 同类**（都是 bash-only 容器内操作，不是 codex/claude-code 那种富工具面）；
2. L1 已证 terminus-2 与厂商原厂 harness 平均打平（Δ = +0.03pp）；
3. ⇒ XEYO 的 harness 偏移先验 = **N(0, 6pp)**；作为未上榜首的第三方 harness，方差只可能更大不会更小；
4. XEYO 另有 TB 定向机制（验证门控 / 收尾窗口 / 后台作业 / LoopLedger），给引擎项 **N(+1, 2pp)**。

蒙特卡洛 20 万次（harness N(0,6) + 引擎 N(+1,2) + 复现 N(0,2.2)）：

| 读法 | 锚点 | mean | 中位 | 90% 区间 | 未截断分位 |
|---|---:|---:|---:|---|---|
| A | 90.3% | 91.0% | 91.3%（81/89） | 80.7%~100% | P5 80.8 / P50 91.3 / **P95 101.9** |
| B | 76.2% | 77.2% | 77.2%（69/89） | 66.7%~87.8% | P5 66.6 / P50 77.2 / P95 87.8 |
| **C（主推）** | **78.0%** | **79.0%** | **79.0%（70/89）** | **68.5%~89.6%** | P5 68.5 / P50 79.0 / P95 89.5 |

读法 C 锚点 = 官方表 90.6 − 口径落差 12.6pp（gpt-5.6-sol 同模型实测）。

**读法 B 与 C 的收敛是本次最重要的发现**：B 假设"90.3 是 pass@5"，C 假设"90.3 是自报口径"——
两条完全独立的路径把锚点分别拉到 76.2% 与 78.0%，**只差 1.8pp**。原读法 A 因此成为孤证
（P(≥95%) 从 28% 降到 1%）。中枢预测：**79%（70/89），区间 68.5%~89.6%**。

## 四、成本

用官方 20 条真实提交的 token 形态 × 你的新价（命中 0.02 / 未命中 1.0 / 输出 4.0 元每百万）折算成"全量 89 题一次"：

| 统计 | 全部 20 条 | 仅 terminus-2 形态（与 XEYO 同类） |
|---|---:|---:|
| 最低 | ¥6.9 | ¥7.7 |
| **中位** | **¥15.6** | **¥15.9** |
| 均值 | ¥18.3 | ¥15.9 |
| 最高 | ¥73.7 | ¥24.9 |

**→ XEYO + v4.1-flash 全量 89 题一次 ≈ ¥16（区间 ¥8~25）。**

三桶结构（官方形态平均）：

| 桶 | 占 token 量 | 占成本 |
|---|---:|---:|
| 缓存命中 | 86% | **11.6%** |
| 未命中 | 14% | 37% |
| **输出** | — | **51%** |

两个决定性事实：
- **成本由 harness 的上下文纪律决定，不是模型单价决定**。输入/trial 从 144k 跨到 3183k（22 倍），全在新价下只差 ¥7.7 vs ¥73.7。同一个模型挂不同 harness，账单能差 3~10 倍。
- **输出仍是最贵的一桶（51%）**，命中段虽占 86% 的量却只占 11.6% 的钱。

## 五、脆点与两支读法的取舍

| 脆点 | 影响 |
|---|---|
| ~~**90.3 的口径未知**~~ | **已基本消解（见 §〇bis）**：B 与 C 两条独立修正收敛到 76.2 / 78.0（差 1.8pp）。残余不确定度 ~2pp。 |
| **口径落差的单点证据** | +12.6pp 只来自 gpt-5.6-sol 一组配对（换的是同模型不同 harness，非同一份提交）。用"5/7 个值高于公开榜首"作为结构旁证，但仍宜向 DeepSeek 直问协议。 |
| harness 偏移 sd 只有 4 个配对样本 | sd 5.0pp 自身的不确定度约 ±40%，MC 已放宽到 6.0pp |
| L3 的杠杆面回归 R²=0.236 | 只用于叙事解释（"为什么 harness 影响小"），未进入点估计 |
| 官方表 TB2.1 值是 **90.6** 而非 90.3 | 读法 B 的反解基于 90.3；若按 90.6 重算 B 会略上移（约 +0.2pp），不影响结论 |

**取舍**：主推 **读法 C**——它有直接证据（公开榜 ↔ 官方表的同模型配对），且与读法 B 独立收敛。
读法 A 需要假设"官方表与公开榜同协议"，而这一假设已被反例推翻。
